# Розширена статистика — дизайн

Дата: 2026-09-24
Джерело побажань: таблиця «Для Сізова» (вкладки «Сезони», «загальна стата», «ще додати»).
Макети: `.superpowers/brainstorm/7565-1790280430/content/` (season-stats, dashboard-seasons, records, profile-leagues).

## Мета

Показати в аппі статистику, яку клуб зараз рахує вручну в Google-таблицях:
підсумки сезону, статистику ведучих, турніри, порівняння сезонів, рекорди за
всі сезони і ліги в профілі гравця. Успіх — кожен показник з доки має місце
в аппі й рахується з уже наявних даних сезонів.

## Загальні правила (діють скрізь)

- **Нерейтингові ігри не рахуються ніде** — ні у вінрейтах, ні в кількості
  ігор, ні в іграх ведучого. Частку нерейтингових теж не показуємо. (Апп уже
  відкидає їх при завантаженні — так і лишається.)
- Порожні блоки ігор (шаблони без гравців) не рахуються.
- Турнірні ігри, що лежать в основній вкладці «Ігри» (сезони 19+), лишаються
  у звичайній статистиці.
- **Ведучі** зводяться до однієї людини з гравцем за тим самим мапінгом
  `players.json` (displayName → id), що й гравці.
- **ПУ** = перший убитий. «% ПУ» рахується від ігор гравця за червоних
  (мирний + шериф).
- **Доп від ведучого (плюс)** за гру = сума додатних значень колонки доп
  гравців гри. Для сезонів 2–3 це ЛИ (1 / 0.5 / 0.5). АД (17–20), ОП,
  бали протоколу (29+) і «Бал ведучого» — **не** рахуються.
- **Мінус від ведучого** за гру =
  - сезони 2–3: −1 за кожного гравця з 4 фолами;
  - сезони 4–20: від'ємні значення колонки доп, **крім −2 (дискваліфікація)**;
  - сезони 21+: колонка «Штраф».
- **Періоди систем допу** для рекордів за всі сезони: **сезони 2–3 (ЛИ)** і
  **сезони 4–30**. Сезони 0–1 без допу — у таблиці з допом не потрапляють.
- UI-тексти нових блоків — англійською, як решта апу.

## 1. Дані й парсер

### 1.1 Ведучий і дата гри
`Game` отримує поля `host` (String?) і `date` (DateTime?).

| Сезони | Де ведучий | Де дата |
|---|---|---|
| 0–1 | нема (null) | нема |
| 2–16 | рядок слоту 9, колонка C (у B надпис «Ведущий» або в 15–16 значення «Доп. Бал» — ігнорується) | рядок слоту 10: B = «Дата», C = дата |
| 17+ | рядок заголовка гри: A = «Дата», B = дата, C = «Ведучий», D = ім'я | там же, B |

Дата парситься з ISO-рядка, `M/D/YYYY` або серійного числа Sheets. Відомі
одруківки (1900, 0202 тощо) — зберігаємо як є, на статистику не впливають.

### 1.2 Плюс/мінус ведучого
Похідні значення на рівні гри за правилами вище: `hostPlus`, `hostMinus`.
Розраховуються з наявних `additionalPoints` / `penaltyPoints` + нового
прапорця «4 фоли» для сезонів 2–3 (колонка F == 4, уже читається для
`penaltyPoints`).

### 1.3 Турніри
Список турнірів кладемо в конфіг сезону (`season_config.json` і
`remote_config.json`, поле `tournaments`):

```json
{"type": "minicap|maxicap|marathon|tournament", "name": "Мінікап 26.03", "games": 4, "date": "2026-03-26"}
```

Початкові дані — зі сторінки «Турніри Family Mafia» (зібрано з Google-таблиць
сезонів 0–30). Типи: мінікап (разом з фіналами мінікапів і «міні міні-капом»),
максікап, марафон, турнір (загальна категорія: кубки, Big/Біг-серія, NoTail,
Alligators, Вівторок, Master Shifu, CheRog, FAS, Ліга №1).
Нагадування: після зміни `remote_config.json` пушити і `master`, і
`feature/flutter_migration`.

### 1.4 Баг «Players»
Лічильник унікальних гравців сезону (`home_providers.dart:64-67`) і в Club
Overview не рахує порожні ніки, `_blank_*` і `kExcludedPlayers` (тестові).

## 2. Екран сезону

Порядок: чипи сезонів → Main/Small → **Season Summary** → Season Awards (без
змін, тільки Main) → **Season Stats** (нове) → Player Ratings.

### 2.1 Season Summary (hero)
Перший ряд без змін: Games · Players · City WR · Mafia WR.
Другий ряд (нове): **Main league** (к-сть гравців) · **Small league** ·
**Tournaments** (к-сть усіх турнірів сезону).

### 2.2 Season Stats (нова картка, варіант A — бейджі)
Сітка 2×N бейджів як у Season Awards; тап відкриває топ-4 під сіткою
(та сама взаємодія `_AwardBadge` → `_AwardRanking`).

| Бейдж | Рахується | Ліга |
|---|---|---|
| Most Games | рейтингових ігор за сезон | поточна (Main/Small) |
| Top ПУ % | ПУ / ігри за червоних | поточна |
| Most Hosted | відведено ігор (+ % від ігор сезону) | тільки Main |
| Host avg доп | середній плюс за гру, мін. 20 відведених ігор | тільки Main |
| Host avg мінус | середній мінус за гру, мін. 20 відведених | тільки Main |
| No host | к-сть ігор без ведучого (без топ-4) | тільки Main; для 0–1 — «no data» |

Під сіткою — чипи турнірів сезону за типами («2 мінікапи · 3 максікапи»),
кольори як на сторінці турнірів.
«Most Killed» лишається нагородою в Season Awards.

## 3. Дашборд — таблиця сезонів (варіант A)

Нова картка «Seasons» між Club Overview і Win Rate by Role.
Горизонтальна прокрутка, колонка «Season» закріплена зліва. Тап по заголовку
— сортування (повторний тап міняє напрям). На дашборді 5 рядків + «Expand» →
повноекранна таблиця з усіма сезонами.

Колонки: Season · Games · City WR · Mafia WR · Players · Main league ·
Minicaps · Maxicaps · Marathons · Tournaments · Most games · MVP · Most ПУ ·
Top ПУ % · Most hosted · Host avg + · Best Don · Best Sheriff · Best Civilian ·
Best Mafia.
Колонки з іменами сортуються за числом біля імені (MVP / Best-ролі — за їхнім
показником з нагород).

## 4. Вкладка Records (варіант A)

Нова вкладка в нижньому меню між Dashboard і Chat (іконка trophy).
Угорі чипи категорій, під ними одна таблиця «гравець + сезон»: топ-10,
«Show all», сортування тапом по заголовку, ранги 1–3 кольорами медалей.
Рекорди рахуються **тільки по вищій лізі**, крім позначених «за весь час»
і серій.

| Категорія | Колонки | Перемикач |
|---|---|---|
| MVP | доп/гра · макс. доп за гру · сумарний доп · WR | 2–3 / 4–30 |
| Roles (Дон, Шериф, Мирний, Мафія) | доп/гра · WR (ігри в ролі) | роль + 2–3 / 4–30 |
| Games | ігор за сезон · WR | Per season / All time (all time — усі гравці) |
| Hosts | відведено ігор · avg + · avg − (мін. 20) | Per season / All time; для avg — 2–3 / 4–30 |
| ПУ | к-сть ПУ · % від ігор за червоних | — |
| Penalties | мінус/гра · макс. мінус за гру · сумарний мінус · WR | 2–3 / 4–30 |
| Streaks | перемог поспіль · сезони (напр. «S18–S19») | — |

**Серії перемог** рахуються по рейтингових іграх гравця в хронологічному
порядку (сезон, потім порядок у таблиці) і **можуть переходити між
сезонами**. Поразка обриває серію. Усі гравці, без фільтра ліги.

## 5. Профіль гравця — секція Leagues (варіант B)

Нова картка після Accomplishments:
- дві великі цифри: **seasons in main league**, **seasons in small league**;
- смужка S0…S30: клітинка на сезон, кольори — Main / Small / грав, але нижче
  порогу / не грав. Тап відкриває цей сезон на вкладці Season.

Вища ліга = ігор ≥ `gameLimit` сезону; мала = від `smallLeagueMinGames` до
`gameLimit` (як у перемикачі Main/Small).

## 6. Архітектура

- Парсер (`game_parsing.dart`): `host`, `date`, прапорець 4 фолів; модель
  `Game` — нові поля.
- `SeasonConfig`: поле `tournaments` (+ модель `Tournament`).
- Нові чисті функції обчислень (без Flutter), кожна у своєму файлі в
  `lib/services/src/`:
  - `host_stats.dart` — по сезону і за весь час, з періодами;
  - `season_extra_stats.dart` — Most Games, Top ПУ %, ліги, турніри;
  - `records.dart` — таблиці рекордів;
  - `win_streaks.dart` — серії з переходом між сезонами;
  - `player_leagues.dart` — ліга гравця по кожному сезону.
- Провайдери Riverpod поруч з екранами (як `home_providers.dart`,
  `dashboard_providers.dart`).
- UI: `season_stats_card.dart` (перевикористати badge/ranking з
  `season_header_card.dart`, винести їх у спільний віджет), `seasons_table.dart`
  (свій легкий sortable table на Row/SizedBox — у проєкті нема DataTable),
  `records_screen.dart`, `leagues_section.dart`.

## 7. Тестування

- Парсер: ведучий і дата для форматів 2–16, 17–28, 29+; сезони 0–1 → null;
  «Доп. Бал» у 15–16 не потрапляє в ім'я.
- Плюс/мінус ведучого: ЛИ у 2–3, −2 виключено, штраф 21+, АД не враховано.
- Ведучий-аліас зводиться з гравцем.
- Серії: обрив поразкою, перехід S18→S19, нерейтингові пропущені.
- Ліги гравця: пороги `gameLimit` / `smallLeagueMinGames`.
- Лічильник Players без `_blank_*` і тестових.
- Звірка з таблицями: к-сть ігор з ведучим по сезонах (раніше підраховано:
  напр. S2 202/213, S16 232/245) і середні плюс/мінус по періодах.
